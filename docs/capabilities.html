PRODUCT OVERVIEW

Everything you can do

A transparent capability map based on the current source code. Features labeled implemented exist in the repository; future modules are explicitly marked.

CURRENT FOUNDATION

Core HR workflows

Implemented

Employee records and access

Create, update, archive and browse employee profiles. Role-scoped visibility, manager/direct-report relationships, one-time invitations and organization access management.

Implemented

Policy-backed leave

Entitlement rules, policy variants, annual carry-over, balances, holidays, half-day requests, overlap protection and manager approvals with transactional ledger accounting.

Implemented

Schedule-aware attendance

Assigned work schedules, grace minutes, check-in/out, overtime, missing or incorrect time record correction workflows and payroll-period summary endpoints.

Implemented

Local-first desktop console

Wails + React HR/admin interface, AES-256-GCM encrypted local employee payloads, OS-keychain-protected sessions and version-aware offline sync.

Implemented

Multi-tenant security model

Organization-scoped PostgreSQL records, JWT access, role enforcement, SameSite/HttpOnly web sessions and auditable HR workflow events.

Implemented

Human-in-the-loop AI assistant

Role-scoped conversational tools for leave, attendance and selected HR workflows. Proposed mutations are saved as single-use actions and require explicit confirmation.

AGENTIC WORKFLOWS

Useful AI with accountability.

Implemented

Read what you are allowed to see

Retrieve authorized balances, leave policies, holidays, attendance, corrections and workforce summaries through existing protected APIs.

Implemented

Prepare, preview and confirm

Draft leave submissions, attendance corrections, manager review actions and limited HR record changes before they are actually executed.

Implemented

Single-use action proposals

PostgreSQL-stored proposals bind an action to actor and tenant, expire after ten minutes and guard against concurrent duplicate confirmations.

Implemented

Separate deployable component

Go agent service behind the Next.js server-side proxy. The HRIS API remains authoritative for every domain and authorization decision.

The assistant does not automatically approve leave, hire people, calculate final payroll, access other tenants or execute unconfirmed writes. Read implementation details ↗
