01 / TIME OFF

Leave requests that respect the policy.

Employees choose dates and leave type. The system checks working days, company holidays, overlap and policy-backed balances. Managers or HR review the pending request, with transactional ledger accounting on approval.

03 / GOVERNED AI

Ask naturally. Approve intentionally.

The assistant calls authorized Go API tools, summarizes live HR data and prepares changes in a time-limited proposal. Nothing mutates until the same authenticated person reviews and confirms the action.

The LLM is not a database administrator or hiring decision-maker.

04 / DESKTOP

HR operations that can tolerate interruptions.

The native HR/admin console encrypts employee data locally and queues updates. On reconnection, it synchronizes with the authenticated API and returns version conflicts rather than silently overwriting someone else's changes.
